# Making-Of: Die Entstehung von biind

> **Zweck:** Dieses Verzeichnis dokumentiert jeden wichtigen Schritt der App-Entwicklung —
> von der ersten Idee bis zum fertigen Produkt. Ziel ist, am Ende zeigen zu können,
> was alles notwendig ist, um so eine App zu bauen. Es ist eben *nicht* nur
> „ich hätt gern eine App" ins Chatfenster schreiben.

## Regeln

1. **Jeder wichtige Schritt bekommt ein Kapitel** (nummerierte Markdown-Datei).
   Wichtig heißt: Entscheidungen, Konzepte, Werkzeuge, Fehlschläge, Meilensteine.
2. **Auch das Warum dokumentieren**, nicht nur das Was. Verworfene Alternativen
   sind Teil der Geschichte.
3. **Echte Artefakte verlinken:** Screenshots und Grafiken nach `../assets/`,
   Konzept-Links, Prompts, Terminal-Ausgaben wo sie erzählenswert sind.
4. **Zeitnah schreiben** — am Ende des Arbeitsschritts, nicht Wochen später.
5. Format je Kapitel: *Datum · Ausgangslage · Was passiert ist · Entscheidungen · Ergebnis*.
